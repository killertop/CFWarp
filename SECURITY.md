# Security policy

Please do not publish WARP account files, WireGuard private keys, SOCKS
passwords, access tokens, server addresses, or complete production logs in an
issue or pull request.

For a suspected vulnerability, contact the maintainer privately with a short
description, affected version, reproduction steps, and mitigation if known.
If a credential may have been exposed, rotate it first and then report the
incident without attaching the secret.

CFwarp is a networking utility, not a guarantee of anonymity, privacy, or
access to any particular service. Review the generated routes, firewall rules,
listening addresses, and applicable service terms before production use.
